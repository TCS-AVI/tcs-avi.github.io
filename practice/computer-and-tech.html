1. Consider the following statements: 1. A computer virus can spread without attaching itself to any host file or program. 2. A worm can replicate itself across a network without needing a host program. 3. A Trojan horse disguises itself as legitimate software. Which of the statements given above is/are correct?

  1. 1 and 2 only
  2. 1 and 3 only
  3. 2 and 3 only
  4. 1, 2 and 3

Answer: C) 2 and 3 only

Statement 1 is false: a virus needs a host; worms are standalone. Statement 2 is true: worms are self-replicating. Statement 3 is true: it does not replicate by itself. So the answer is 2 and 3 only.

  2. 2 and 3 only

4. Match List I with List II. List I: A. FTP; B. SMTP; C. DNS; D. DHCP List II: 1. Dynamic assignment of IP addresses; 2. File transfer; 3. Name resolution; 4. Sending e-mail Choose the correct combination.

  1. A-1, B-4, C-3, D-2
  2. A-2, B-3, C-4, D-1
  3. A-2, B-4, C-1, D-3
  4. A-2, B-4, C-3, D-1

Answer: D) A-2, B-4, C-3, D-1

FTP transfers files between computers (A-2). SMTP sends e-mail (B-4). DNS resolves domain names to IP addresses (C-3). DHCP dynamically assigns IP addresses to devices on a network (D-1).

5. Assertion (A): A website that uses HTTPS is always safe and genuine. Reason (R): HTTPS encrypts data exchanged between the browser and the web server. Choose the correct option.

  1. A is false but R is true
  2. Both A and R are true and R is the correct explanation of A
  3. A is true but R is false
  4. Both A and R are true but R is not the correct explanation of A

Answer: A) A is false but R is true

R is true: HTTPS uses TLS encryption to protect data in transit. A is false: encryption does not verify the intent of the site owner, and phishing or malicious sites can also obtain HTTPS certificates. So encryption does not guarantee genuineness.

6. Which one of the following statements about computer networks is NOT correct?

  1. A LAN covers a small geographical area such as a building
  2. Bluetooth is a WAN technology
  3. A WAN covers a large geographical area
  4. A router connects different networks

Answer: B) Bluetooth is a WAN technology

A LAN spans a limited area like an office. A WAN spans cities or countries. A router forwards packets between networks. Bluetooth is a short-range wireless technology used for a personal area network (PAN), not a WAN, so that statement is incorrect.

7. Which one of the following is NOT a safe cyber practice?

  1. Using strong and unique passwords
  2. Enabling two-factor authentication
  3. Sharing an OTP with a caller claiming to be from the bank
  4. Installing security updates regularly

Answer: C) Sharing an OTP with a caller claiming to be from the bank

Strong unique passwords, two-factor authentication and regular updates reduce risk. An OTP is a secret that must never be shared; banks do not ask for it by phone, and callers who do are usually fraudsters carrying out vishing.
